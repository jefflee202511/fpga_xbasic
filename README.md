xBasic for FPGA or ASIC 
=================

## 🚀 Why xBasic

* 🎯 **Easy Hardware Design** — XBasic makes hardware design easy and fun for hobbyists.
* ⚡ **Bring up in 5 Minutes** — Install XBasic and test your design on a real board within five minutes.
* 💻 **No HDL Required** — Use primitive BASIC without learning a separate HDL.



## 🛠️ How to Use

1. 🔍 **Check Your Board**
   - supported FPGA board: **iCESugar or iCEBreaker**.

2. 🐍 **Install Python**
   - Install the latest version of Python.

3. 📦 **Install Apio**
   - Install Apio with pip:
   `pip install apio`

4. 💡 **Create Your Project**
   - Create a project and try a basic LED or button example.
   *Samples coming soon.*

5. 📡 **Test UART Output**
   Run:
   `PRINT "Hello xBasic!"`
   - Check the output via UART at **115200 baud**.
